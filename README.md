# Pokémon World Tournament Simulation

This project simulates large-scale Pokémon tournaments using a modified Pokémon Showdown battle engine.

The simulator can run thousands of battles programmatically and analyze the results using:

- Elo rankings
- Bradley-Terry rankings
- Trainer win rates
- Matchup heatmaps
- Battle statistics

The goal of the project is to compare trainers and teams using simulation and statistical modeling rather than individual battles.

## Interactive Project

View the project here:

Python, Pokémon Showdown, multithreading, Elo ratings, Bradley-Terry models, and data visualization.
